# Путешествия по России 🇷🇺

Адаптивный одностраничный сайт, который знакомит пользователя с ключевыми маршрутами по России.

## Ключевая функциональность

- ✨ Адаптивная сетка, которая подстраивается под экраны от 320 до 1280+ пикселей.
- 💡 Информационные блоки с фактами и маршрутами, собранные в читаемую структуру.
- 🖼️ Галерея изображений с равномерной сеткой и оптимизированными для веба картинками.
- 📚 Контентная часть с реальными источниками и ссылками на дополнительные материалы.
- 🛠️ Единый стиль типографики и цвета за счёт пользовательских шрифтов и CSS-переменных.
- ✅ Контроль качества кода через Stylelint и единые стилистические правила.

## Технологический стек

- **Клиентская часть:** HTML5, CSS3, Flexbox, CSS Grid, адаптивные изображения.
- **Методологии:** БЭМ, подход «сначала для мобильных устройств», семантическая вёрстка.
- **Инфраструктура и инструменты:** Node.js, NPM, Stylelint, Prettier.
- **Дизайн и типографика:** Normalize.css, пользовательские веб-шрифты Inter, адаптивная
  типографика.

## Установка и запуск

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/IrinaRyazanskaya/russian-travel.git
   cd russian-travel
   ```

2. Установите зависимости (нужен Node.js версии 22+):

   ```bash
   npm install
   ```

3. Запустите локальный сервер для просмотра вёрстки:

   ```bash
   npm run serve
   ```

4. Откройте страницу в браузере по адресу, который появится в терминале (по умолчанию
   `http://localhost:3000`), либо просто откройте `index.html` напрямую.

## Скрипты для работы

- `npm run serve` — поднимает локальный сервер для предпросмотра.
- `npm run lint` — проверяет CSS на соответствие Stylelint правилам.
- `npm run lint-fix` — автоматически исправляет найденные линтером замечания.
- `npm run format` — форматирует файлы с помощью Prettier.

## Решённые технические задачи

- Настроена адаптивная сетка на CSS Grid с собственными точками адаптации, чтобы секции корректно
  перестраивались на планшетах и мобильных устройствах.
- Применена методология БЭМ для масштабируемости и повторного использования стилей без конфликтов.
- Настроен Stylelint с конфигурацией `stylelint-config-clean-order`, что обеспечивает
  последовательность правил и единый порядок CSS-свойств.
- Подключены пользовательские шрифты Inter и унифицирована типографика, чтобы текст был читаемым и
  единообразным на всех устройствах.
